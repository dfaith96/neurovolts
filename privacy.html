Privacy policy

Website concept · Updated November 3, 2026

This policy describes the current static Neurovoltz marketing website. It does not describe a future energy platform or its data practices.

Information this website collects

This static website has no user accounts, web forms, analytics, or advertising trackers. The contact links open an email draft in your email application. If you send a message, Neurovoltz will receive the information you choose to include.

External resources

Website photography is loaded from Pexels image servers. The stylesheet uses system fonts and does not request external font files. When hosted, the hosting provider may process standard server logs such as IP address, request time, and requested page.

Illustrative dashboard

The dashboard shown on the website is a visual concept and does not connect to a live model, energy system, or connected hardware.

Contact

For privacy questions, contact hello@neurovoltz.com. This address should be configured as a monitored inbox before public launch.

Future product

A deployed product would require a separate privacy notice describing its actual data collection, purposes, access controls, retention, and security practices.
